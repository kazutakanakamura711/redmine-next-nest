# 変更をレビューする

実際の差分と関連する呼び出し経路をレビューする。`AGENTS.md` と、変更した振る舞いを規定するドキュメントだけを読む。

次の順序で指摘を優先する。

1. 認証、認可、プロジェクトをまたぐアクセス、秘密情報、機微なログ出力
2. データ整合性、transaction 境界、バリデーション、安全でない migration
3. Controller、Service、Repository、Prisma の責務の不一致
4. REST 契約、UI 状態、レスポンシブ表示、アクセシビリティの後退
5. Vitest、結合テスト、Playwright における重要なテストの不足

ツールですでに強制されているスタイルだけの指摘は除外する。重大度順に、具体的な根拠・影響・修正案とともに指摘を報告する。続けて未解決の質問と簡潔な結論を示す。別途依頼されない限り、ファイルは編集しない。
